# 📘 一、什么是“介词 + which 引导的定语从句”

👉 **定语从句**：修饰名词的从句。  
**“介词 + which 引导的定语从句” → 在句子中作** **定语**，修饰前面的名词（先行词），介词 + which 在从句里一起充当 **介词宾语**
👉 当关系代词在从句中作 **介词的宾语** 时，可以把介词提前放在 **which/whom** 前面。

- 口语：The chair (which) I sat on
    
- 书面语：The chair **on which** I sat ✅
    

---

# 📗 二、基础例句（简单）

这些句子主干都很短，容易看懂：

1. **The room in which we live is small.**  
    = The room (which) we live in.  
    （我们住的房间很小。）
    
2. **The day on which he arrived was rainy.**  
    = The day (which) he arrived on.  
    （他到达的那一天是雨天。）
    
3. **The tools with which he fixed the bike are expensive.**  
    = The tools (which) he fixed the bike with.  
    （他修自行车用的工具很贵。）
    
4. **The means by which people communicate have changed.**  
    （人们交流的方式已经改变。）
    

---

# 📙 三、进阶例句（稍复杂）

1. **The speed with which modern technology develops is astonishing.**  
    （现代科技发展的速度令人吃惊。）
    
2. **The way in which he solved the problem impressed everyone.**  
    （他解决问题的方式让大家印象深刻。）
    
3. **The reason for which they refused the offer was unclear.**  
    = The reason why they refused the offer was unclear.  
    （他们拒绝提议的原因不清楚。）

# 📕 四、长难句（考研/专八真题风格）

1. **We are living in an age in which the accumulation of knowledge is proceeding at an unprecedented rate, bringing both opportunities and challenges.**  
    （我们生活在一个知识积累以前所未有速度推进的时代，这既带来机会，也带来挑战。）
    

👉 结构分析：

- 主句：We are living in an age
    
- 定语从句：in which the accumulation of knowledge is proceeding at an unprecedented rate
    
- 后置非谓语：bringing both opportunities and challenges
    

---

2. **Globalization has created a context in which different cultures interact more frequently, a process by which both conflicts and mutual understanding may arise.**  
    （全球化创造了一个不同文化更频繁交流的语境，这一过程可能引发冲突，也可能促进相互理解。）
    

👉 结构分析：

- 主句：Globalization has created a context
    
- 定语从句：in which different cultures interact more frequently
    
- 同位语 + 定语从句：a process by which both conflicts and mutual understanding may arise
    

---

# 📌 五、总结口诀

- **口语**：The chair (which) I sat on
    
- **书面**：The chair **on which** I sat ✅
    
- **常考先行词 + 介词**：
    
    - way/manner → in which
        
    - day/time/occasion → on which
        
    - reason → for which (= why)
        
    - tool/method/means → by which / with which
        
    - situation/context → in which
        

---

✅ 这样你能看到 **由浅入深**：

- **简单句** → 先行词清晰 + 定语从句短
    
- **进阶句** → 增加抽象名词（way, reason, means）
    
- **长难句** → 结合抽象名词 + 非谓语/同位语，考研/专八常见
