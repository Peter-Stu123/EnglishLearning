# 🟢 一、什么是强调句

**强调句 = 为了突出句子中的某个成分（主语、宾语、状语、表语等），通过特殊句型将其置于句首，从而强调该部分。**

核心特点：

1. 通过 **It…that / What…/ All…/ The very…** 等结构实现强调
    
2. 被强调的部分通常是 **真正的主语 / 宾语 / 状语 / 表语 / 时间 /地点**
    
3. 常用于书面语、演讲和作文中，提升语气和句式层次
    

---

# 🟡 二、强调句的基本句型

## 1️⃣ It…that / It…who 强调主语、宾语、状语或表语

### 结构

- **It + be + 被强调部分 + that/who + 其他部分**
    

### 例句

1. **强调主语**
    

- Original: John won the prize.
    
- Emphasis: **It was John who won the prize.**
    
- 中文：获奖的是约翰。
    

2. **强调宾语**
    

- Original: I met Mary yesterday.
    
- Emphasis: **It was Mary that I met yesterday.**
    
- 中文：我昨天见到的是玛丽。
    

3. **强调状语（时间/地点/方式）**
    

- Original: He came yesterday.
    
- Emphasis: **It was yesterday that he came.**
    
- 中文：他来的时间是昨天。
    

4. **强调表语**
    

- Original: The problem is the lack of resources.
    
- Emphasis: **It is the lack of resources that is the problem.**
    
- 中文：问题是资源不足。
    

**考点**：

- **that/who** 后面仍保留原句结构
    
- 宾语或状语强调时，主句要用 It + be
    
- 考研作文和阅读中常考 **It…that 强调宾语/状语**
    

---

## 2️⃣ What… 强调主语或宾语

### 结构

- **What + 被强调部分 + 动词 + 其他部分**
    

### 例句

1. **强调主语**
    

- **What surprised me** was his honesty.
    
- 中文：让我吃惊的是他的诚实。
    

2. **强调宾语**
    

- I don’t understand **what he wants**.
    
- 中文：我不明白他想要什么。
    

**考点**：

- What 本身就是名词性从句，可作主语或宾语
    
- 可结合强调句或复合句使用
    

---

## 3️⃣ All / The very / The only / The first / The last … 强调限定意义

### 例句

1. **All + 名词 + 谓语**
    

- **All I want** is peace.
    
- 中文：我想要的只有和平。
    

2. **The very** 强调特定的人或事
    

- This is **the very book** I needed.
    
- 中文：这正是我需要的那本书。
    

3. **The only / The first / The last**
    

- He is **the only person** who can help.
    
- 中文：他是唯一能帮忙的人。
    

---

# 🟠 三、强调句的变体和技巧

1. **倒装强调**
    

- Rarely / Only / Not until + 倒装结构 → 强调句首
    
- 例：**Only by working hard** can you succeed.
    
- 中文：只有努力工作，你才能成功。
    

2. **分词短语 + 强调**
    

- **Shocked by the news**, it was John who cried first.
    
- 中文：被消息震惊，最先哭的是约翰。
    

3. **非谓语强调**
    

- **To win the prize** was his dream.
    
- 中文：赢得奖项是他的梦想。

# 🔵 四、翻译技巧

|英文强调句|中文翻译技巧|
|---|---|
|It is/was + 被强调成分 + that/who + 其他|“正是……”，“是……才……”|
|What + …|“……的事情/东西/人是……”|
|All / The very / The only …|“全部/正是/唯一/第一/最后”|
|倒装强调|“只有……才……”|
|非谓语强调|“……是……的”或“……是……的事情”|

---

# 🔴 五、考研 / 专八高频点

1. **It…that/who 强调主语/宾语/状语**（高频改错/翻译/写作）
    
2. **What 引导强调句**（阅读理解中出现）
    
3. **All / The very / The only …** 强调特定对象
    
4. **倒装强调句**（Only / Rarely / Not until）
    
5. **分词 / 不定式作强调**
    
6. **考点陷阱**：不要混淆强调句和被动句，It + be + 强调成分是固定结构

# 🟤 六、速记表

|强调类型|句型|例句|中文|
|---|---|---|---|
|主语|It is/was + 主语 + that/who|**It was John who** won the prize.|获奖的是约翰|
|宾语|It is/was + 宾语 + that/who|It was Mary **that I met yesterday**.|我昨天见到的是玛丽|
|状语|It is/was + 时间/地点/方式 + that|It was yesterday **that he came**.|他来的时间是昨天|
|表语|It is/was + 表语 + that|It is the lack of resources **that is the problem**.|问题是资源不足|
|What 强调|What + 主语/宾语 + 谓语|**What surprised me** was his honesty.|让我吃惊的是他的诚实|
|限定词强调|All / The very / The only / The first / The last|**All I want** is peace.|我想要的只有和平|
|倒装强调|Only / Rarely / Not until + 倒装|**Only by working hard** can you succeed.|只有努力工作，你才能成功|

---

✅ **总结记忆技巧**

1. **It + be + 强调成分 + that/who** → 强调主语/宾语/状语/表语
    
2. **What + …** → 强调主语/宾语
    
3. **All / The only / The very …** → 强调限定
    
4. **Only / Rarely / Not until + 倒装** → 强调条件或频率
    
5. **分词/不定式可作强调** → 非谓语强调句
    
6. **翻译原则**：把英文强调句的核心成分放在中文前面或用“正是/只有/才”突出
